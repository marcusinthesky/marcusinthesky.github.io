# Heritage SVG source artwork

Original vector motifs for the portfolio's heritage layer. These files are the archival source; the
site does not serve them. The website renders the motifs from typed React parts in
`src/typescript/packages/ui/src/heritage/`, which carry the same geometry, keep the `data-part` hooks,
and take colour from theme tokens rather than the hex values embedded here.

## Folders

- `prain/`: heraldic components (lotus, rose, shuttle, palms, prayer hands, torse, motto) and the
  assembled shield and crest.
- `institutions/`: original SACS and UCT heraldic renderings plus the anchor, lamp and mural-crown
  parts they share.
- `heritage/`: rook, open book, route and Table Mountain motifs.
- `patterns/`: dividers, page ornament and the repeatable scatter pattern.
- `composites/`: assembled marks.

The full arms and shields are kept for a future heritage section and are not used on the site. See
`DESIGN.md` for usage rules and `SOURCE-NOTES.md` for heraldic provenance and institutional-brand
caveats.
